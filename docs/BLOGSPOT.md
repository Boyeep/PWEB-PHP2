# Artikel Blogger

**Judul** Membuat Login Multi-Peran dan CRUD Akun PPDB dengan PHP

**Label** Pemrograman Web, PHP, MySQL, PDO, Bootstrap, RBAC, PPDB

Salin isi [blogspot.html](blogspot.html) ke editor Blogger melalui Tampilan HTML. Jika tema sudah mencetak judul posting, hapus elemen `h1` dari isi sebelum menerbitkan. Tangkapan layar ditautkan dari GitHub.

Versi web tersedia di [RuangAkses](https://pweb-php2.vercel.app/blog).
